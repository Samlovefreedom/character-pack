# 表情包管理 (Meme Packs)

本目录用于存放自定义表情包。通过「个性化配置中心」网页端导入的表情包均会保存在此目录，并自动优化同步至 AstrBot 插件中。

### 目录结构说明

每个表情包作为一个独立子文件夹，例如：
```
memes/
├── 自定义表情包A/
│   ├── manifest.json       # 表情包元数据配置（自动生成）
│   └── memes/              # 表情图片素材（.jpg / .png / .gif / .webp）
│       ├── 01.gif
│       └── 02.png
└── README.md
```

### 功能特点
1. **图片格式过滤**：自动过滤非图片垃圾文件（如 `.DS_Store`, `Thumbs.db`）。
2. **MD5 智能去重**：自动剔除内容重复的表情图片。
3. **自动生成清单**：自动生成 `manifest.json` 并注册至 AstrBot `meme_manager`。
4. **一键双向对齐**：支持一键将本地表情包同步至 AstrBot 实例。
